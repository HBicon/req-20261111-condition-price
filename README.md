# 成色价展示

需求 ID：`REQ-20261111-001`

在现有手机回收报价详情页基础上，新增“成色价”价格展示样式。用户可在“预估价 / 成色价”之间切换，并按靓机、小花、大花、外爆、内爆五档成色查看对应回收价。

## 交互说明

- 默认展示“成色价”，主价格显示当前选中的成色价格，五档价格同时露出，便于横向比较。
- 点击任一成色，主价格、价格说明、较靓机价差额和底部报价同步更新。
- 切换至“预估价”后，恢复原报价页的大价格与“预估下周”趋势信息。
- “判定标准”打开底部说明，解释五档成色的判定口径。
- 屏幕显示、电池健康度支持单选；功能异常支持多选和折叠。
- 成色价是演示数据：靓机 `¥4,923`、小花 `¥4,650`、大花 `¥4,180`、外爆 `¥3,260`、内爆 `¥2,450`。
