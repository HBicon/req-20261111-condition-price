# 成色价展示

需求 ID：`REQ-20261111-001`

在现有手机回收报价详情页基础上，新增“成色价”价格展示样式。用户可在“预估价 / 成色价”之间切换，并按靓机、小花、大花、外爆、内爆五档成色查看对应最新估价。

本次方案调整增加后台“价格段加价”配置：不同成色基础价命中不同价格段后，额外叠加配置金额，前台展示叠加后的最新估价。

## 交互说明

- 默认展示“成色价”，主价格显示当前选中成色的最新估价，五档价格同时露出，便于横向比较。
- 主价格下方拆解为“成色基础价 + 价格段加价”，并展示命中的价格段，金额口径可追溯。
- 点击任一成色，主价格、价格说明、拆解金额和底部报价同步更新。
- 切换至“预估价”后，恢复报价页的大价格与趋势信息，同时按同一套价格段配置叠加金额。
- “判定标准”打开底部说明，解释五档成色的判定口径。
- 屏幕显示、电池健康度支持单选；功能异常支持多选和折叠。
- 成色基础价是演示数据：靓机 `¥4,923`、小花 `¥4,650`、大花 `¥4,180`、外爆 `¥3,260`、内爆 `¥2,450`。

## 后台配置

访问 `/config.html` 进入“价格段加价配置”菜单。

- 默认六档规则：`0–2,999 +¥50`、`3,000–3,999 +¥100`、`4,000–4,499 +¥150`、`4,500–4,999 +¥200`、`5,000–5,999 +¥250`、`6,000 以上 +¥300`。
- 支持新增、编辑、启用停用、删除和恢复默认规则。
- 同一基础价仅命中一条启用规则；启用规则的价格区间不允许重叠。
- 未命中任何启用规则时，最新估价按基础价展示，不额外加价。
- 右侧实时预览五档成色的基础价、加价金额和最新估价。
- 配置保存在浏览器 `localStorage`，前后台页面实时同步，仅用于静态原型演示。

最新估价计算口径：`成色基础价 + 命中价格段加价 = 最新估价`。
