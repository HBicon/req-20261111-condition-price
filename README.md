# 成色价展示与虚拟加价配置

需求 ID：`REQ-20261111-001`

本次迭代交付两个内容：

1. `config.html`：后台“虚拟加价配置”交互原型。
2. `产品文档.md` / `index.html`：根据后台配置菜单整理的产品文档。

前台报价页面已存在于现有系统，本次不输出前台原型页面，后台配置页也不提供前台效果预览或前台页面跳转入口。

## 交付内容

### 后台配置原型

访问 `config.html`，支持：

- 按应用渠道配置估价金额最低值、最高值、虚拟加价系数和封顶金额。
- 应用渠道父子层级与子渠道继承；子渠道匹配规则优先于父渠道。
- 新增、编辑、启用停用、删除和恢复默认规则。
- 同渠道启用区间重叠校验，不同渠道允许相同区间。
- 单条规则表单内的计算试算摘要，不包含前台页面预览。

原型配置保存在浏览器 `localStorage`，仅用于静态交互演示，不代表正式服务端存储。

### 产品文档

产品文档覆盖：

- 背景、目标、本期范围与明确不做事项。
- 后台菜单、列表字段、表单字段与校验规则。
- 应用渠道树、继承优先级和异常回退规则。
- 虚拟加价与新估价计算公式，单值价及区间价处理口径。
- 操作状态、权限审计、前台接入字段和验收标准。
- 默认规则与待确认项。
